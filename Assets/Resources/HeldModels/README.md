# Held Models (weapons / tools / shields)

Drop each downloaded handheld model in here and **rename it to the slug listed below**
(the equip system will load it by that name from `Resources/HeldModels/`).

Any model format works (.fbx / .obj / .glb). One file per item. Keep names exact and lowercase.
